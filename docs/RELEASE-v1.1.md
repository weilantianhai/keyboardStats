# KeyboardStats v1.1

## 新增

- **手柄悬停显示数据**：鼠标悬停在手柄面板任意部件上弹出数值——按键显示「手柄B 506 次」，  
  摇杆大圈与 LT/RT 柱显示**累计行程**（如「左摇杆 行程 12.3 次」）。行程的后缀跟随  
  「行程显示单位」开关（次 / mm），与计数列表同一口径。
- **数据文件合并**：设置页「数据文件」行新增 `合并` 按钮，把文件夹里除当前文件外的所有  
  数据文件并入当前文件并删除源文件（新建过多个文件、转入过文件时用）。按月自动模式下会  
  拒绝并提示先新建或选择一个文件。
- **手柄面板**
- **设置页大屏两栏**：可用宽度 ≥ 1500 物理像素时自动分左右两列（设置项 / 数据位置），  
  窄窗口回退单列竖排。

## 变更

- **直方图归一化**：单独筛选键盘 / 鼠标 / 手柄时，柱高改用**组内峰值**——所选组内最高的  
  键顶满绘图区，不再被别组的数值压平；`全部` / `分开` 仍用全局峰值（跨组可比，行为不变）。  
  右上角「最多：XX」也跟随当前筛选。
- **数据同步改为事件驱动**：记录进程落盘后直接通知界面，界面立即增量读入——不再是每  
  0.5 秒轮询文件。数据延迟从「缓冲 5 秒 + 最多 0.5 秒」降到「缓冲 5 秒 + 几乎为零」。

## 修复

- **界面卡顿**
- **开机自启动拔掉电源后失效**
